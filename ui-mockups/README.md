# ui-mockups

Mockups of the games' UI screens. Each screen is designed on a Claude Design canvas. When the
owner approves a version, its export is filed here in a folder named for the screen, and the
game's UI is built from it. The working rules are in [AGENTS.md](AGENTS.md).

## Screens

None yet. Each screen gets a row here: its canvas link, its approved export, and whether it is in
design, approved or built.
