# The generator's public functions: the only fwg:: functions a sibling component may call.
#
# One function per line, then the fwg/api/ header(s) that forward its declaration:
#
#   <function> <api-header> [<api-header> ...]
#
# tools/check_layers holds a sibling to this list. It reads the list from the LAST COMMIT, so
# a function lands here in one commit and gains its first caller in the next. It also
# refuses an entry the named header does not declare, so the list cannot drift from the code.
#
# Adding a line widens the public surface: say why in the commit. What stays off the list is
# the point of it: the stage passes, the in-place World& mutators (rebuild_tail,
# age_transition, mark_corrupted, raise_refugees, ...) and the board steps a request API
# already runs.
